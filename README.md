# PhishCheck

A small multi-page course on recognising phishing: types of attack, an interactive red-flag explorer, real cases, safety habits and a 20-question quiz.

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Run it locally
Open `index.html` in a browser. That's all.

## Put it on GitHub Pages
1. Create a new repository on github.com (for example `phishcheck`).
2. Upload everything in this folder (keep the `css` and `js` folders as they are).
3. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/phishcheck/`.

## Before you publish
- Replace `YOUR NAME HERE` in the footer of each page.
- Quiz questions live in `js/quiz.js`. Keep the answer options a similar length so the right one doesn't stand out.
